# supersvelte

Biblioteka Svelte 5 zawiera 755 ikon SVG oraz komponenty interfejsu.

## Uruchamianie

- `pnpm install`
- Workflow `supersvelte web` uruchamia frontend.
- Workflow `supersvelte API` uruchamia serwer Rust.
- `pnpm run typecheck` i `pnpm run build` sprawdzają aplikację.

## Struktura

- `supersvelte/` — frontend, API Rust, ikony i komponenty.
- `packages/icons/` i `packages/components/` — osobne paczki npm organizacji `pricewaterbase`.
- `attached_assets/` — oryginalne archiwa źródłowe użytkownika.
